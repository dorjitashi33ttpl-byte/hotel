# 📱 Hotel Masterpiece SaaS - Native Mobile Companion

A native-optimized React Native application for the modern high-end traveler.

## ✨ Highlights
- **Contactless Stay**: Digital QR keys and pre-arrival identity verification.
- **Native Performance**: Native-stack navigation, biometric login (FaceID/Fingerprint), and Haptic feedback.
- **Offline Resiliency**: AsyncStorage-backed persistent caching for "My Trips".
- **Logistics**: Real-time Mapbox route previews and arrival time updates.

## 🛠 Tech Stack
- **Core**: React Native, Expo, TypeScript
- **Sync**: WebSockets for instant inventory & staff notifications.
- **UX**: SafeArea management, Skeleton loaders, and Pull-to-refresh.

## 📦 Local Setup
1. `npm install`
2. `npx expo start`
